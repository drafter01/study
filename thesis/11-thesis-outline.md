# 11. 논문 개요 v3 (지도교수 면담용 요약)

> v3 변경: ①RQ4에 비영리 적용을 넣음 ②중심 주장, 배경, 적용의 위계를 정리함 ③프레임워크 검증에 서면 전문가 검토를 추가함
> 표기: (연구자 해석) = 근거에서 연구자가 끌어낸 해석, (잠정) = 시범 분석이나 초안 단계의 결과

## 가제
관계를 설계하는 UX: 취향·활동 기반 커뮤니티 경험 설계로의 UX 디자이너 역할 확장 연구

## 논문의 위계
| 층위 | 내용 | 논문 속 위치 |
|---|---|---|
| **중심 주장** | UX 디자이너의 역할은 사용자와 시스템의 관계를 넘어, 사용자와 사용자 사이의 관계를 설계하는 일로 확장될 수 있다 | 제목, 연구 질문, 5~6장 |
| **배경** | 커뮤니티가 중요해졌다: 외로움이라는 사회 문제, 취향·활동 커뮤니티의 확산, 비영리 참여 방식의 변화 | 1~2장 |
| **적용** | 비영리 커뮤니티 | 6~8장 |

## 연구 배경
1. **UX의 간극**: UX의 본래 정의는 "기업, 서비스, 제품과의 모든 상호작용"(Norman & Nielsen 1998)이지만, 국내 UX 공고의 98%는 앱·웹 화면을 다루고 오프라인 경험을 포함하는 공고는 2%에 그친다 (잠정, 원티드 200건 시범 분석)
2. **커뮤니티의 중요성**
   - 외로움과 고립이 정책 의제가 됨: WHO(2025) 외로움 관련 사망 연 87만 1천 명 추정, 청년 고립·은둔 2022년 2.4% → 2024년 5.2%, 서울시 '외로움 없는 서울', 복지부 사회적 고립 예방 추진단
   - 사람들은 취향·활동으로 가볍게 모이는 커뮤니티를 선호하면서도 소속감과 다정한 관계를 원함: 러닝크루, 당근모임 가입자 +125%, 초단기 모임 선호, 소프트 소셜라이징
   - 비영리도 같은 변화를 겪음: 기부 참여율 2015년 29.9% → 2025년 26.1%, 20대 정기 후원 감소, 사안별 기부와 참여형 기부(기부런) 확산, 계단뿌셔클럽처럼 취향·활동 방식으로 참여를 모으는 사례 등장

## 연구 동기
연구자는 비영리 생태계에 기여하고자 한다. 비영리는 회원, 후원자, 봉사자라는 커뮤니티로 움직이며, 최근의 참여 방식 변화는 취향·활동 커뮤니티의 트렌드와 닮아 있다. 따라서 취향·활동 커뮤니티에서 도출한 경험 설계 방법은 비영리 참여에도 적용될 가능성이 있다 (연구자 해석, RQ4와 전문가 검토로 확인).

## 문제 제기
커뮤니티는 운영자의 직관과 헌신에 기대어 운영되며(불참, 갈등, 번아웃), 구성원 경험을 설계하고 평가할 방법이 현장에 부족하다. 경험 설계를 전문으로 하는 UX 디자이너는 이 영역에서 거의 역할을 하지 않으며, 커뮤니티 플랫폼에서도 UX의 범위는 화면에서 멈춘다.

## 연구 질문
- RQ1. 국내 UX 디자이너의 역할 범위는 현재 어떻게 정의되어 있는가?
- RQ2. 현대 취향·활동 기반 커뮤니티에서 구성원의 경험을 좌우하는 요소는 무엇인가?
- RQ3. UX 디자인 방법은 커뮤니티 경험 설계에 어디까지 적용될 수 있으며, 무엇이 확장되거나 전환되어야 하는가?
- RQ4. 커뮤니티 경험 설계 프레임워크는 어떤 모습이며, **비영리 커뮤니티에는 어떻게 적용될 수 있는가?**

## 연구 범위
- 주 대상: 취향·활동을 매개로 모이고 온라인 채널과 오프라인 만남이 혼합된 소규모 커뮤니티 (러닝크루, 독서모임, 원데이 모임 등)
- 적용 대상: 비영리 커뮤니티 (자원봉사 기반 모임, 참여형 공익 활동 등)

## 연구 방법
| RQ | 방법 | 상태 |
|---|---|---|
| RQ1 | 채용공고 내용분석 (원티드 외 여러 플랫폼, 500건 이상 목표), 선행연구 | 시범 200건 완료 |
| RQ2 | 문헌연구, 2차 자료 질적 종합, 온라인 설문 (만 19~39세, 100명 이상, 커뮤니티 참여 경험 + 비영리 참여 경험) | 2차 자료 17건 확보, 설문 초안 v0.1 |
| RQ3 | UX 방법과 커뮤니티 문제의 대응 분석 | 12개 문제, A·B·C 유형 초안 |
| RQ4 | 프레임워크 도출 → 사례 적용(취향 커뮤니티 + 비영리) → **서면 전문가 검토** | 미착수 |

### 서면 전문가 검토 (RQ4)
- 대상: UX 디자이너 3~5명, 비영리·커뮤니티 운영자 3~5명
- 방식: 프레임워크 요약본과 서면 질문지를 보내고 서면으로 응답받음 (인터뷰 없음)
- 평가 항목: 이해 용이성, 실무 활용 가능성, 빠진 요소, 비영리 맥락에서의 적용 가능성
- 결과 반영: 응답을 정리해 프레임워크 수정안을 제시

## 현재까지의 주요 발견 (잠정)
1. 국내 UX 실무는 화면 중심이며, '서비스 디자인'이라는 말도 대부분 디지털 화면을 뜻한다
2. 현대 커뮤니티의 핵심 과제는 가벼운 참여를 지속적인 소속감으로 전환하는 것이며, 단계마다 설계 긴장이 존재한다 (낮은 문턱 ↔ 의도된 마찰, 소속감 ↔ 배타성 등) (연구자 해석)
3. UX 방법은 일부 그대로 통하고(A), 일부는 확장이 필요하며(B), 일부는 관점 전환이 필요하다(C). 그 핵심은 설계 대상이 사용자-시스템 관계에서 사용자-사용자 관계로 옮겨간다는 점이다 (연구자 해석, Preece 2000의 사용성·사회성 구분과 같은 맥락)

## 예상 기여
- 학술: UX 역할 확장 논의에 "사용자-사용자 관계의 설계"라는 관점과 국내 실증 근거를 제시
- 실무: UX 디자이너와 커뮤니티 운영자가 함께 쓸 수 있는 커뮤니티 경험 설계 프레임워크
- 사회: 비영리 조직이 참여 경험을 설계하는 데 쓸 수 있는 시사점
- 전시: 프레임워크를 체험하게 하는 커뮤니티 시뮬레이션 게임 (추후)

## 한계
- 1차 인터뷰 없이 2차 자료, 온라인 설문, 서면 전문가 검토에 의존
- 프레임워크의 현장 적용 효과는 검증하지 못함
- 후속 연구: 운영자·구성원 인터뷰, 실제 커뮤니티에 프레임워크를 적용한 현장 연구

## 목차와 분량 (총 약 85~105쪽)
| 장 | 내용 | 분량 |
|---|---|---|
| 1. 서론 | 배경, 연구 동기(비영리), 문제 제기, 연구 질문, 범위와 방법 | 7~9쪽 |
| 2. 이론적 배경 | 커뮤니티의 변화, 공동체 의식, 참여 단계, UX의 정의와 확장, UX·CX·서비스디자인 위치 정리, 비영리 생태계와 커뮤니티(Skocpol과 Putnam의 관점), 연구 공백 | 20~25쪽 |
| 3. 국내 UX 디자이너의 역할 현황 | 채용공고 분석 (RQ1) | 8~10쪽 |
| 4. 현대 커뮤니티 경험 분석 | 2차 자료 종합, 온라인 설문, 사례(러닝크루, 동행클럽, 문토, parkrun, 계단뿌셔클럽) (RQ2) | 15~18쪽 |
| 5. UX 방법과 커뮤니티 문제의 대응 분석 | A·B·C 유형, 사용자-사용자 관계로의 이동 (RQ3) | 8~10쪽 |
| 6. 커뮤니티 경험 설계 프레임워크 | 구조, 원칙, 핵심 질문 (RQ4) | 10~12쪽 |
| 7. 프레임워크 적용과 검토 | 사례 적용(취향 커뮤니티 + 비영리 1개 이상), 서면 전문가 검토, 수정안 (RQ4) | 10~12쪽 |
| 8. 결론 | 요약, 기여, 비영리 생태계에 주는 시사점, 한계, 후속 연구 | 5~6쪽 |
| 참고문헌, 부록 | 설문지, 전문가 검토 질문지, 코딩 기준표, 공고 목록 | 10~14쪽 |
