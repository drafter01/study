# 21. 디자이너 대상 예비 설문 (RQ3 적합성, 약 5분)

> 목적: "커뮤니티 과제는 UX 과업과 닮았다"는 연구자의 실무 관찰을, 답을 유도하지 않는 방식으로 확인
> 성격: 연구자가 아는 디자이너 커뮤니티에 올리는 편의 표본 → 논문에서는 "예비 조사"로 보고, 일반화하지 않음

## 유도를 줄이는 원칙
1. 가설을 드러내지 않는다 ("UX 과업과 닮았다", "온보딩" 같은 말을 쓰지 않음)
2. 떠올리게 한 뒤 평가하게 한다 (자유 응답 상황 질문 → 평가 문항 순서)
3. 비교 대상을 섞는다 (UX와 닮은 일 + 운영·행정 + 관계·거버넌스)
4. 디자인과의 연결은 응답자가 고르게 한다 ("디자인 경험이 도움이 되나요?" 대신 자신감 + 그 출처)

## 게시글
- 제목: 커뮤니티·모임 운영에 관한 5분 설문 부탁드려요 (졸업논문 예비 조사)
- 안내: 졸업논문 예비 조사로, 커뮤니티나 모임을 운영하는 상황을 어떻게 바라보는지 묻는 짧은 설문입니다. 정답은 없고 익명으로 진행되며, 개인을 알아볼 수 있는 정보는 수집하지 않습니다. 응답은 연구 목적으로만 사용합니다. 언제든 중단하셔도 됩니다. ☐ 확인했고 참여에 동의합니다

## 문항
### 1. 기본 정보
- Q1 현재 직무: UX/UI 디자이너 / 프로덕트 디자이너 / UX 리서처 / 그 외 디자인 직무 / 기타
- Q2 실무 경력: 1년 미만 / 1~3년 / 3~7년 / 7년 이상
- Q3 커뮤니티·모임 운영 경험(복수): 없음 / 일회성 모임 주최 / 정기 모임 운영 / 업무로 커뮤니티 운영
### 2. 상황 질문 (자유 응답)
- Q4 동네에서 매주 모이는 15명 규모의 독서모임 운영을 맡게 되었습니다. 최근 석 달 동안 매번 3분의 1 정도가 말없이 빠집니다. 어떻게 하시겠어요? 생각나는 순서대로 적어주세요.
- Q5 모임에 처음 온 사람이 다음 모임에 다시 오는 경우가 적습니다. 무엇을 확인하고, 무엇을 해보시겠어요?
### 3. 평가 질문
- Q6 아래 일을 맡는다면 어느 정도 자신 있게 해낼 수 있을 것 같나요? (1 전혀 자신 없다 ~ 5 매우 자신 있다 / 잘 모르겠다) — 구글 폼 격자형, 항목 순서 섞기
  1. 처음 온 사람이 어색하지 않도록 첫 모임 진행 방식 정하기
  2. 다시 오지 않는 사람들의 이유 알아내기
  3. 모임 소개글과 신청 과정 만들기
  4. 모임이 끝난 뒤 의견을 받아 다음 모임에 반영하기
  5. 모임 방식을 조금씩 바꿔보고 반응 비교하기
  6. 회비를 걷고 정산하기
  7. 모임 장소를 찾고 예약하기
  8. 멤버 사이의 말다툼 중재하기
  9. 분위기를 해치는 멤버에게 주의 주기
  10. 오래된 멤버와 새 멤버가 잘 섞이게 하기
  11. 운영을 도와줄 사람을 찾고 일을 나누기
- Q7 자신 있다고 답한 일은 주로 어떤 경험 덕분인가요?(복수): 디자인 업무 경험 / 커뮤니티·모임 경험 / 디자인이 아닌 다른 업무 경험 / 일상생활 경험 / 기타
- Q8 가장 자신 없는 일과 그 이유
### 4. 마지막 (선택, 앞 문항에 영향을 주지 않도록 맨 끝)
- Q9 기회가 있다면 직접 커뮤니티나 모임을 만들어볼 생각이 있나요? (1~5) / 망설여진다면 가장 큰 이유는?

## 분석 계획 (응답 수집 전에 고정)
- Q4·Q5 자유 응답 분류 기준
  - 디자인 방법: 조사·인터뷰·설문, 흐름이나 접점 점검, 가설과 실험, 피드백 반영과 반복
  - 운영·관계 방법: 개별 연락, 규칙·벌칙, 친목·뒤풀이, 리더·운영진 지정
  - 기타
  → 묻지 않았는데 디자인 방법을 먼저 꺼내는 비율 = 적합성의 근거
- Q6 묶음 (응답자에게 비공개, 10번 대응표 기준)
  - UX 과업과 닮은 일: 1~5 / 운영·행정: 6~7 / 관계·거버넌스: 8~11
  - 묶음별 평균 비교. 1~5 > 8~11이면 A 유형(통함)과 B·C 유형(확장·전환 필요)의 근거. 다르게 나와도 그대로 보고
- Q7: 자신감의 출처로 "디자인 업무 경험"을 고른 비율
- Q3 운영 경험 유무에 따라 Q6 비교 (경험 효과와 디자인 효과 구분)

## 확인 사항
- 커뮤니티 관리자에게 게시 허락
- 학교 IRB 필요 여부
- 목표 응답 수: 30명 이상이면 묶음별 비교를 서술적으로 보고 가능 (통계 검정은 하지 않음)
