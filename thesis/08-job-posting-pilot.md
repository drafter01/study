# 08. 채용공고 시범 분석 (P2 근거)

## 방법
- 수집일: 2026-10-26
- 출처: 원티드 직군 태그 'UX 디자이너'(tag 599) 최신순 공고 200건 (목록: `data/wanted_ux_2026-10-26.csv`, 스크립트: `scripts/`)
- 분석 대상 텍스트: 주요 업무 + 자격 요건 + 우대 사항 + 공고 제목 (회사 소개와 복지는 제외)
- 1차: 키워드 자동 코딩 → 2차: 드문 범주(서비스·오프라인, 커뮤니티)는 문맥을 직접 읽고 재분류

## 결과 2. 문맥을 읽고 재분류
- '서비스 디자인'이라는 말이 나온 24건 중 22건은 "웹·앱 서비스 디자인", "커머스 서비스 디자인"처럼 **디지털 서비스 화면 설계**라는 뜻 → 국내 실무에서는 서비스디자인이라는 말 자체가 디지털 쪽으로 좁아져 있음
- 오프라인·물리적 경험이 실제 업무 범위에 들어간 공고: 약 4건(2%) (동행클럽, 코코지, 알고케어, 올쏘케어). 나머지 오프라인 언급은 오프라인 광고물 제작이나 결제 같은 도메인 이름
- '커뮤니티' 관련 25건의 대부분은 ①커뮤니티 서비스 **도메인 경험 우대**, ②피드·댓글·DM 같은 **디지털 커뮤니티 기능** 설계
- 구성원의 관계 경험을 오프라인까지 포함해 다루는 공고는 1건(0.5%): 동행클럽(구 넷플연가)

## 사례
- **문토** (누적 회원 140만, 국내 최대 관심사 기반 커뮤니티): 프로덕트 디자이너는 "고객이 서비스를 만나는 **모든 화면과 브랜드 경험**"을 설계. 입사 후 첫 과제는 "모임을 탐색하고 신청하는 과정의 **화면** 점검". 모임 현장 경험이나 호스트 경험은 업무에 없음 → 커뮤니티 플랫폼에서도 UX의 범위는 화면에서 멈춤
- **동행클럽(구 넷플연가)**: 주요 업무에 "좋은 **오프라인 경험과 연계**한 디자인 개선안", "좋은 사람을 연결하는 더 나은 방법" 포함. 우대 사항에 "사람·관계에 대한 애정", "오프라인 현장에 관심을 갖고 직접 경험해보고 싶은 분" → **확장의 초기 신호**. 다만 핵심 업무는 여전히 앱·웹 UI/UX

## 해석
- P2 지지: 국내 UX 디자이너의 업무 대상은 거의 전부 앱·웹 화면(98%), 오프라인을 포함하는 경우는 2%
- 동시에 커뮤니티 기업에서 관계와 오프라인 경험을 언급하기 시작함 → "확장될 수 있다"는 주장의 현실적 근거

## 한계와 본 분석 계획
- 한 플랫폼, 한 시점, 200건. 키워드 코딩은 문맥을 놓칠 수 있음
- 본 분석: 원티드 + 다른 플랫폼(사람인, 리멤버 등), 서비스디자이너·커뮤니티 매니저 직군과 비교, 코딩 기준표를 정해 2인 이상 교차 코딩 또는 연구자 재검토
