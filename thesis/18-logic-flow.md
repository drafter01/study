## 한 문장 주장
커뮤니티 경험은 설계로 달라지는 대상이고 그 설계 과정은 UX 방법과 구조가 같다. 따라서 국내에서 화면에 머물러 온 UX 디자이너의 역할은 구성원 사이의 관계를 설계하는 일로 확장될 수 있다. 단, 그러려면 마찰 제거·효율 중심의 관점을 관계·윤리 중심으로 바꿔야 한다.

## 전체 흐름
문제(간극) → 이론(무엇이 공동체를 만드나, 디자인은 어디까지 가능한가) → 현황(UX는 화면에 있다) → 현장(커뮤니티 경험은 단계와 긴장으로 된 설계 문제다) → 대응(UX는 일부 통하고, 일부는 확장, 일부는 전환해야 한다) → 제안(프레임워크) → 검증(사례 적용, 전문가 검토, 비영리 적용) → 의의

## 장별 논리
### 1장 서론
- 배경 ①UX의 간극: 본래 정의는 "기업·서비스·제품과의 모든 상호작용"(Norman & Nielsen 1998) ↔ 국내 공고 97%가 화면 ✅
- 배경 ②커뮤니티의 중요성: WHO 2025, 청년 고립 2.4→5.2%, 외로움 정책화 / 취향·활동 커뮤니티 확산 / 비영리 참여 방식의 변화 ✅
- 동기: 비영리 생태계 기여 / 문제 제기: 커뮤니티는 직관과 헌신에 기대고, UX는 화면에서 멈춘다 ✅
- RQ1~RQ4, 범위(주 대상: 취향·활동 혼합형 소규모 커뮤니티, 적용 대상: 비영리), 방법
- → 넘기는 문장: "커뮤니티를 설계 대상으로 다루려면 먼저 무엇이 공동체를 만드는지, 디자인이 어디까지 다룰 수 있는지 정리해야 한다"

### 2장 이론적 배경
1. 커뮤니티의 변화와 취향공동체: 느슨한 연결, 일상 비중 10% 안팎, 언제든 탈연결(구선아·장원호 2020, 오지현 외 2021) ✅ → **핵심 모순: 가볍게 참여하고 싶지만 소속감은 원한다**
2. 공동체 의식: 네 요소와 하위 속성(McMillan & Chavis 1986) ✅ → 판단 기준 / 이론 스스로 "공동체 의식을 만드는 사람(조직가)"을 상정 → **공동체 의식은 의도적으로 만들어질 수 있다** (연구자 해석)
3. 참여의 단계: 합법적 주변 참여(Lave & Wenger 1991), Reader-to-Leader(Preece & Shneiderman 2009) 🟡 원문 필요 → 가벼운 참여는 실패가 아니라 첫 단계
4. UX의 정의와 디자인 영역의 확장: NN/g, ISO, Buchanan(1992), 김상욱(2016) "상호작용의 형식 자체를 계획", Manzini(2015) 🟡
5. 위치 정리: UX(사용자↔화면), CX(고객↔기업), 서비스디자인(고객↔시스템), 이 연구(구성원↔구성원) ✅
6. 비영리와 커뮤니티: 참여 방식 변화, Skocpol(조직 구조) vs Putnam(개인 요인) ✅ 단, 인과는 "대응할 수 있는 조건 가운데 하나"로 한정
7. 연구 공백: 온라인 중심 이론, 운영자 관점, 가벼운 참여 전제 부족, 국내 UX 실무 연구 부재, 2030 취향 모임 질적 연구 부재
- → 넘기는 문장: "그렇다면 지금 국내 UX 디자이너는 실제로 무엇을 설계하고 있는가"

### 3장 국내 UX 디자이너의 역할 현황 (RQ1, P2)
- 방법: 원티드 UX·UI·UX 리서처 공고 274건 전수, 설계 대상 기준표, 곽민지 외(2021) 방법 선례 ✅
- 결과: 화면 97.1%, 오프라인 서비스 0.7%, 관계 경험 0.4% / '서비스 디자인'도 디지털 화면을 뜻함 / 커뮤니티 직무는 마케팅·운영·기획에 있고 디자인 직군에는 0건 ✅
- 해석: 커뮤니티 경험 설계라는 일은 현장에 있지만 디자인 방법 없이 디자이너 밖에서 이뤄진다 (연구자 해석)
- 보강: 2차 시점 수집, 무작위 30건 교차 분류 ⬜
- → 넘기는 문장: "그 커뮤니티 현장에서 구성원은 어떤 경험을 하고, 무엇이 그 경험을 좌우하는가"

### 4장 현대 커뮤니티 경험 분석 (RQ2, P3·P4·P6)
- 자료: 국내 질적 연구(신민철 외, 오지현 외, 구선아·장원호), 해외 HCI(Lu 외, Pethig 외, parkrun), 운영자 사례(넷플연가 모임장, 병아리 러닝크루), 온라인 설문 ⬜
- 결과 ①단계별 경험 요인: 진입(불확실성·포용감) / 재방문(첫 반응·리듬) / 정착(반복·함께하는 활동·정체성) / 주도(위임·자율) ✅ (진입·이탈은 설문으로 보강)
- 결과 ②단계마다 설계 긴장: 낮은 문턱↔의도된 마찰 / 자유↔리듬 / 소속감↔배타성 / 핵심층↔개방 ✅ (연구자 해석)
- 결과 ③반복 패턴: 온·오프라인 보완, 신구 분화, 운영자가 첫 만남을 설계 ✅
- 결과 ④현장의 한계: 구성원 경험 평가 도구 부재, 운영자 직관 의존과 번아웃 ✅
- 결론: 커뮤니티 경험은 단계와 긴장으로 구성된 **설계 문제**다
- → 넘기는 문장: "이 설계 문제를 UX 방법으로 어디까지 풀 수 있는가"

### 5장 UX 방법과 커뮤니티 문제의 대응 분석 (RQ3, P5)
- 12개 현장 문제 × UX 방법 ✅ 초안
- A 그대로 통한다(모객, 이탈 분석, 측정·HEART) / B 확장해야 한다(화면→현장·백스테이지, 시스템의 반응→구성원의 반응) / C 관점을 바꿔야 한다(마찰의 양, 배제와 윤리, 규범과 권한)
- 핵심: UX의 설계 대상이 **사용자-시스템 관계에서 사용자-사용자 관계로** 옮겨간다 (연구자 해석, Preece의 사용성·사회성 구분과 일치)
- 디자이너의 권한 문제(이소영·백준상 2021, 3장 결과)를 C의 일부로 포함
- → 넘기는 문장: "그렇다면 UX 디자이너가 이 확장과 전환을 실제로 수행하려면 어떤 틀이 필요한가"

### 6장 커뮤니티 경험 설계 프레임워크 (RQ4) ⬜
- 구조(안): 시간 축(진입→재방문→정착→주도) × 설계 대상(목적·활동·관계·규칙·접점) + 단계별 설계 긴장 + 판단 기준(공동체 의식 4요소 + 행동 신호)
- 수준: 전술이 아니라 원칙과 핵심 질문
- 근거 연결: 각 칸의 원칙은 4장 결과와 2장 이론에서 도출

### 7장 프레임워크 적용과 검토 (RQ4) ⬜
- 사례 적용: 취향 커뮤니티(러닝크루, 트레바리 또는 동행클럽) + 비영리(parkrun 또는 계단뿌셔클럽)
- 서면 전문가 검토: UX 3~5명, 커뮤니티·비영리 운영자 3~5명, 요소별 관련성·명확성 + 전체 평가
- 수정안 제시

### 8장 결론
- RQ별 답 요약 / 기여(학술: 사용자-사용자 관계라는 관점과 국내 실증, 실무: 프레임워크, 사회: 비영리 시사점)
- 한계: 1차 인터뷰 없음, 원티드 한 플랫폼, 현장 효과 미검증 / 후속 연구: 인터뷰, 현장 적용
