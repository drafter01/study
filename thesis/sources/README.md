# sources

원문 PDF를 넣는 폴더예요. (저작권 자료이므로 공개 레포에 올리지 말 것)

## 파일 이름 규칙
저자_연도_짧은제목.pdf (예: 오지현_2021_트레바리.pdf, Peterson_2008_BSCS.pdf)

## 읽기 규칙 (토큰 절약)
1. PDF를 통째로 읽지 않는다
2. `pdftotext -layout 파일.pdf 파일.txt`로 텍스트 변환 후, 필요한 키워드·쪽만 찾아 읽는다
3. 읽은 결과는 `notes/저자_연도.md`에 요약, 인용문(쪽수 포함), 논문에서 쓸 곳을 정리해 두고 이후에는 노트만 참고한다
