# 03. 연구 방향 구체화 (v0.2)

## 제약
- 1차 인터뷰 없음 → 2차 자료(학술 논문, 공개 인터뷰, 기업 자료) 중심
- 연구자 본인의 커뮤니티 경험 없음 → 공개 자료 기반 사례 분석

## 연구 방법
| RQ | 방법 | 자료 |
|---|---|---|
| RQ1 국내 UX 역할 범위 | 채용공고 내용분석 + 선행연구 | 원티드 등 UX 공고 약 100건 직접 수집·코딩, 곽민기 외(2021) |
| RQ2 커뮤니티 경험의 핵심 요소 | 문헌연구 + 2차 자료 질적 종합 | 국내외 질적 연구, 운영자·참여자 공개 인터뷰 |
| RQ3 UX 방법론의 적용 범위와 한계 | 개념 매핑 | Preece, Kraut & Resnick, 서비스디자인 문헌 |
| RQ4 프레임워크 | 종합 → 사례 적용으로 설명력 검토 | 러닝크루, 넷플연가, 당근모임 등 공개 사례 |

## 핵심 2차 자료 (확보)
- 곽민기 외 (2021). 국내 실무에서 요구되는 UX디자이너 핵심 역량 분석. *Journal of Integrated Design Research*, 20(1), 39-52. doi:10.21195/jidr.2021.20.1.003 → 공고 분석 + 실무자 인터뷰. 업무가 앱·웹에서 브랜딩·콘텐츠로 확장 중
- 신민철·한승우·강유원 (2025). MZ세대는 왜 뛰며 관계 맺는가? 러닝크루 문화의 현상학적 고찰. *한국체육과학회지 인문사회과학편*, 34(4), 88-105. → 14명 심층면담. 주제: ①함께 달리며 만들어지는 느슨하지만 지지적인 관계 ②낮은 진입장벽 ③기록 공유로 자신을 드러내기(온·오프라인 연결)
- James Lang (2025). If you can design an app, you can design a community. Rosenfeld Media 강연 → UX가 커뮤니티를 해결 영역으로 다루지 않았다는 실무자 문제 제기
- 넷플연가 전희재 대표 인터뷰 (한경 긱스, 2023), 넷플연가 호스트 사례

## 프레임워크의 추상화 수준
철학·원리 → **프레임워크(무엇을, 언제, 어떤 기준으로)** → 방법·도구 → 전술(버디 지정 등)
- 프레임워크는 "설계 원칙 + 핵심 질문"까지
- 전술은 프레임워크에 넣지 않고 사례 적용 장에서 예시로만 사용

## 프레임워크 구조 v0.2
- 시간 축 (구성원 전환 4단계): 진입(발견→첫 참여) / 재방문(첫 참여→재참여) / 정착(재참여→소속) / 주도(소속→기여)
- 설계 대상 (디자이너가 다루는 것): 목적 · 활동 · 관계 · 규칙 · 접점(온·오프라인)
- 결과 기준 (공동체 의식): 소속감 · 영향력 · 욕구 충족 · 정서적 연결
- 칸에는 설계 원칙과 핵심 질문을 넣는다
