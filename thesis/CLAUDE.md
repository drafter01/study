# 졸업논문 프로젝트 인수인계 (Claude용)

이 폴더는 졸업논문 연구 작업 공간이다. 이전 세션(클라우드)에서 진행한 내용을 이어받는다. 대화는 한국어로 한다.

## 연구 개요
- 가제: 관계를 설계하는 UX: 취향·활동 기반 커뮤니티 경험 설계로의 UX 디자이너 역할 확장 연구
- 중심 주장: UX 디자이너의 역할은 사용자-시스템 관계를 넘어 사용자-사용자 관계를 설계하는 일로 확장될 수 있다. 단, 효율·마찰 제거 중심 관점을 관계·윤리 중심으로 전환해야 한다
- 범위: 주 대상은 취향·활동 기반 온·오프라인 혼합형 소규모 커뮤니티(러닝크루, 독서모임 등), 적용 대상은 비영리 커뮤니티(B안: 범위는 유지하고 적용 영역으로 연결)
- 연구자 동기: 비영리 생태계에 기여하고 싶음
- 분량: 70~100쪽
- 연구 질문
  - RQ1 국내 UX 디자이너의 역할 범위는 어떻게 정의되어 있는가?
  - RQ2 취향·활동 커뮤니티에서 구성원 경험을 좌우하는 요소는?
  - RQ3 UX 방법은 어디까지 적용되며 무엇이 확장·전환되어야 하는가?
  - RQ4 커뮤니티 경험 설계 프레임워크는 어떤 모습이며, 비영리 커뮤니티에는 어떻게 적용될 수 있는가?
- 방법: 채용공고 분석(완료), 2차 자료 종합, 온라인 설문(가능, 초안 있음), 대응 분석, 프레임워크 → 사례 적용 + 서면 전문가 검토. 1차 인터뷰는 하지 않음
