# 졸업논문 프로젝트 인수인계 (Claude용)

이 폴더는 졸업논문 연구 작업 공간이다. 이전 세션(클라우드)에서 진행한 내용을 이어받는다. 대화는 한국어로 한다.

## 연구 개요 (v4, 최신 기준은 11-thesis-outline.md)
- 제목: **만드는 디자이너, 관계를 설계하다**: AI 시대 UX 디자이너의 실천을 커뮤니티로 확장하기
- 중심 주장: AI로 UX 디자이너는 직접 만드는 사람이 되어 가지만 만드는 대상은 디지털에 머문다. 커뮤니티 과제는 UX 과업과 닮아 디자이너가 만들 수 있는 대상이 될 수 있다. 단, 사람 사이의 관계·현장·지속 운영·의도된 마찰에서 다르므로 관점 전환이 필요하다
- 행위자: 커뮤니티를 직접 만들고 가꾸려는 디자이너 (취업 시장 이야기가 아님). AI는 "왜 지금인가"의 배경으로만
- 왜 커뮤니티인가: 필요(외로움·비영리) + 적합성(커뮤니티 과제 ≈ 온보딩·리텐션·조사·실험) + 시점(AI 직접 구현)
- 범위: 취향·활동 기반 온·오프라인 혼합형 소규모 커뮤니티 / 적용 대상: 비영리 커뮤니티
- 연구자: UX 디자이너이며 커뮤니티를 운영하는 회사에 재직 중. 비영리 생태계에 기여하고 싶음
- 분량: 70~100쪽
- 연구 질문
  - RQ1 국내 UX 디자이너가 설계하고 직접 만드는 대상은 무엇이며, AI로 어떻게 변하고 있는가?
  - RQ2 취향·활동 커뮤니티에서 구성원 경험을 좌우하는 요소는?
  - RQ3 커뮤니티 과제는 UX 과업과 어디까지 닮았으며, 무엇이 확장·전환되어야 하는가?
  - RQ4 커뮤니티를 직접 만들려는 디자이너를 위한 프레임워크는 어떤 모습이며, 비영리에는 어떻게 적용되는가?
- 방법: 채용공고 분석(완료), 2차 자료 종합(원문 7편 노트 완료), 온라인 설문(초안), 대응 분석, 프레임워크 → 사례 적용 + 서면 전문가 검토. 1차 인터뷰는 하지 않음
- "제품"은 제목에 쓰지 않고, 본문에서 정의해 비유로만 사용
