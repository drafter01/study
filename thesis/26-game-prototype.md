# 26. 전시 게임 프로토타입 v0.1 「모임 설계자」

> 파일: game/moim.html (브라우저에서 바로 실행) / 아티팩트: https://claude.ai/artifact/4xBE5Z2iPMn4CGckNbQ35E (비공개)
> 상태: 프레임워크 v0.1 전에 만든 탐색용 프로토타입. 프레임워크가 나오면 카드·게이지·사건을 그 구조에 맞춰 바꾼다 (게임을 만들며 프레임워크의 애매한 곳을 찾는 용도로도 사용)

## 한 판의 흐름 (3~5분)
1. 모임 고르기: 동네 독서모임 / 저녁 러닝크루 / 플로깅 봉사 모임(비영리)
2. 모임 8번: 매번 카드 4장 중 운영자 에너지 안에서 최대 2장
3. 2·4·6번째 모임 뒤 사건(두 선택지 딜레마)
4. 리포트: 결과 유형, 가입자 수 vs 관계 신호, 공동체 의식 게이지, 기울었던 긴장
5. 전시용: 리포트 90초, 플레이 중 3분 동안 입력이 없으면 처음 화면으로

## 연구와의 연결
| 게임 요소 | 연구 근거 |
|---|---|
| 구성원 단계(처음 온 → 다시 온 → 자리 잡은 → 함께 이끄는) | 참여 단계(Reader-to-Leader, Lang 동심원), 05번 단계별 종합 |
| 게이지(소속감·영향력·욕구 충족·정서적 연결) | McMillan & Chavis(1986) 공동체 의식 4요소 |
| 열린 정도 게이지 | 소속감 ↔ 배타성 긴장 |
| 카드의 긴장 표시 | 05·17번 설계 긴장 4개(문턱↔마찰, 자유↔리듬, 열린 관계↔끈끈함, 넓히기↔핵심층) |
| 운영자 에너지 | 09번 운영자 번아웃 사례, "출시 후에도 가꿔야 함" |
| 게이지 자연 감소 | 지속 운영(관점 전환 C 유형) |
| 사건 6개 | 09번 사례: 1/3 불참, 신구 갈등, 무례한 멤버, 운영자 과부하, 대중화, 장소 문제(오프라인) |
| 리포트의 "가입자 수로만 보면" | Lang의 행동 신호, 07번 평가 도구(허영 지표 경계) |
| 의견 듣기 카드 | UX 방법(조사·회고)의 A 유형 이전 |

## 결과 유형
스스로 굴러가는 모임 / 운영자가 지친 모임 / 북적이지만 머무르지 않는 모임 / 끈끈하지만 닫힌 모임 / 아직 뿌리내리지 못한 모임 / 조용히 자라는 모임

## 밸런스 확인 (자동 플레이 각 8판, 잠정)
- 유입 위주 전략(홍보·문턱 낮추기·자유 참여): 8판 모두 "북적이지만 머무르지 않는 모임"
- 관계 위주 전략(역할·맞이·섞기·나눔·리듬): 좋은 결과가 섞여 나오지만 아직 운에 따른 편차가 큼

## 주의
- 수치는 게임 디자인을 위해 정한 값이며 연구 결과가 아님 → 화면과 전시 설명문에 명시
- 카드 일부(뒤풀이, 단톡방 등)는 전술 수준. 게임에서는 체험을 위해 허용하되, 프레임워크 본문은 원칙·질문 수준 유지
