# 14. 온라인 설문 초안 v0.1

## 목적
- RQ2 보완: 2차 자료로 도출한 단계별 경험(진입 → 재방문 → 정착 → 주도)을 국내 20~30대 응답으로 확인
- 비영리 연결: 취향·활동 커뮤니티 참여와 비영리 참여(기부, 봉사, 회원 활동) 경험 비교
- 성격: 탐색적 기술 조사 (가설 검정 아님)

## 대상과 규모
- 최근 1년 안에 취향·활동 기반 모임에 1회 이상 참여한 만 19~39세
- 목표 100명 이상 (단계·유형별 교차 분석을 위해)
- 모집: 인스타그램, 에브리타임, 오픈채팅·러닝크루·독서모임 커뮤니티 공지 (운영자 허락 후), 지인 확산
- 도구: 구글 폼 또는 네이버 폼, 응답 시간 10~12분 목표

## 윤리
- 첫 화면에 연구 목적, 익명성, 자발적 참여, 언제든 중단 가능, 데이터 사용 범위 안내 + 동의 체크
- 개인 식별 정보 수집 안 함 (경품을 줄 경우 연락처는 별도 폼으로 분리)
- 학교의 IRB(연구윤리심의) 필요 여부 확인

## 문항 구성
### 0. 동의와 선별
- Q0-1 연구 참여 동의
- Q0-2 최근 1년 안에 취향·활동 모임(운동, 독서, 영화, 원데이 클래스, 봉사 모임 등)에 참여한 적이 있나요? → 아니오면 종료

### 1. 참여 현황
- Q1-1 참여한 모임 유형 (복수: 러닝·운동 / 독서 / 영화·콘텐츠 / 음식·소셜 다이닝 / 취미·클래스 / 봉사·공익 / 기타)
- Q1-2 모임을 찾은 경로 (복수: 카카오톡 오픈채팅 / 당근 / 소모임 / 문토 / 트레바리·동행클럽 등 유료 멤버십 / 인스타그램 / 지인 소개 / 기타)
- Q1-3 참여 방식 (일회성 위주 / 정기 위주 / 둘 다)
- Q1-4 가장 오래 참여한 모임의 참여 기간

### 2. 진입: 처음 참여하기까지
- Q2-1 처음 참여하기 전 망설인 이유 (복수: 누가 오는지 몰라서 / 어색할까 봐 / 활동을 잘 못할까 봐 / 이미 친한 사람들끼리일까 봐 / 시간 / 비용 / 안전 걱정 / 망설이지 않음 / 기타)
- Q2-2 참여를 결정하게 한 요인 (복수: 활동 자체가 재미있어 보여서 / 지인과 함께 / 모임 소개가 구체적이어서 / 후기 / 가격 / 가까운 위치 / 부담 없는 일회성이라서 / 기타)
- Q2-3 첫 모임에서 가장 기억에 남는 순간 (주관식, 좋았던 것이든 불편했던 것이든)

### 3. 재방문: 다시 가거나 가지 않은 이유
- Q3-1 처음 참여한 모임에 다시 갔나요? (예 / 아니오)
- Q3-2 [예] 다시 간 이유 (복수: 사람이 좋아서 / 활동이 좋아서 / 정해진 일정이 있어서 / 누군가 다시 와달라고 해서 / 기록·목표 때문에 / 기타)
- Q3-3 [아니오] 다시 가지 않은 이유 (복수: 사람이 맞지 않아서 / 분위기에 끼기 어려워서 / 활동이 기대와 달라서 / 시간 / 비용 / 원래 한 번만 가려고 해서 / 기타)

### 4. 정착: 소속감
- Q4-1 공동체 의식 척도: Brief Sense of Community Scale(Peterson 외 2008) 8문항을 번안해 사용, 5점 척도 (원문 확보 후 번안, 번안 과정 기록)
- Q4-2 그 모임에 "속해 있다"고 처음 느낀 계기 (주관식)
- Q4-3 모임에서 불편했던 경험 (복수: 끼리끼리 문화 / 기존 멤버와 신규 멤버의 온도 차 / 무례한 참여자 / 위계·서열 / 원치 않는 친목·술자리 / 이성 관계 문제 / 없음 / 기타)

### 5. 주도: 역할 맡기
- Q5-1 모임에서 운영이나 역할(모임장, 운영진, 총무, 신입 안내 등)을 맡아본 적이 있나요?
- Q5-2 [예] 맡게 된 계기 / 가장 힘들었던 점 (주관식)

### 6. 온라인과 오프라인
- Q6-1 모임 밖에서 쓰는 온라인 채널 (복수: 단톡방 / 인스타그램 / 기록 앱(Strava 등) / 플랫폼 앱 / 없음)
- Q6-2 온라인 활동이 오프라인 관계에 준 영향 (5점: 매우 방해됨 ~ 매우 도움됨) + 이유 (주관식, 선택)

### 7. 비영리 참여
- Q7-1 최근 1년 안에 한 활동 (복수: 정기 후원 / 일시 기부 / 자원봉사 / 시민단체·비영리 회원 활동 / 기부런·플로깅 같은 참여형 기부 / 없음)
- Q7-2 비영리 활동을 하다가 그만두거나 줄인 경험이 있다면 그 이유 (복수: 시간 / 비용 / 단체에 대한 신뢰 / 활동이 의미 있게 느껴지지 않아서 / 함께하는 사람이 없어서 / 내 역할이 없다고 느껴서 / 해당 없음 / 기타)
- Q7-3 "취미 모임처럼 재미있고 함께하는 방식이라면 공익 활동에 더 참여할 것 같다" (5점 척도)
- Q7-4 그렇게 생각하는 이유 (주관식, 선택)

### 8. 기본 정보
- 연령대, 성별(선택), 거주 지역(광역), 직업 상태

## 분석 계획
- 객관식: 빈도와 교차 분석 (예: 일회성 위주 vs 정기 위주별 망설임 이유, 재방문 여부별 첫 경험)
- 공동체 의식 점수: 참여 기간, 역할 경험, 온라인 채널 사용에 따른 차이 비교
- 주관식: 진입·재방문·정착·주도 단계와 설계 대상(목적·활동·관계·규칙·접점)으로 코딩
- 비영리: Q7과 Q2·Q3를 비교해 참여 장벽이 비슷한지 확인

## 확인 필요
- Brief Sense of Community Scale 원문과 문항, 국내 번안 사례
- 학교 IRB 규정
- 예비 조사: 5명에게 먼저 응답받아 문항 이해도와 소요 시간 확인
